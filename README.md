### 📂 Featured Projects

**Retail Demand Forecasting — Machine Learning Comparison**

A reproducible forecasting project using a sample of 50 product-store series from Walmart's M5 dataset. Compares Random Forest, LightGBM, and XGBoost against a seasonal-naive baseline using rolling one-step-ahead and fixed-origin 28-day evaluation.

[View Project Repository](https://github.com/rahnuma-afrin-opi/retail-demand-forecasting)

**Exchange Rate Volatility Modeling — GARCH**

A research presentation comparing GARCH-based approaches to modeling exchange-rate volatility across selected SAARC countries, presented at an international statistics and data science conference.
